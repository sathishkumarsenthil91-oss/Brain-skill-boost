# BrainBoost - AI Career & Learning Acceleration

BrainBoost is an AI-powered career readiness and learning platform built for students and early-career professionals. It helps users:

- assess skills and identify gaps
- discover personalized learning roadmaps
- explore courses, certifications, and opportunities
- get AI guidance for coding, interviews, and career planning
- review job/internship opportunities for fraud risk
- connect with a professional learning network

This project combines a React frontend, a Node/Express backend, and AI integrations for personalized support.

## Features

- AI-powered career guidance and learning assistant
- Personalized skill tracking and roadmap generation
- Skill gap analysis
- Course and resource recommendations
- Certification and opportunity discovery
- Job/internship safety scanning
- Networking/community-style connectivity section
- Dark mode support
- Supabase-powered profile and persistence
- Google Gemini and OpenAI fallback AI integrations

## Tech Stack

- Frontend: React + TypeScript + Vite
- Backend: Node.js + Express + TypeScript
- AI: Google Gemini + OpenAI
- Database/Auth: Supabase
- Styling: Tailwind CSS
- Deployment: Vercel / AWS Amplify friendly configuration
